# Code of Conduct

## Our Commitment

We are committed to keeping this community open, respectful, and safe for everyone, regardless of age, identity, experience, nationality, religion, sexual orientation, or technical background.

## Expected Behavior

- Use respectful and constructive language.
- Accept technical feedback with a collaborative mindset.
- Focus discussions on code and ideas, not on people.
- Help create an inclusive environment for new contributors.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Publishing private information without permission.
- Discriminatory comments or offensive content.
- Behavior that deliberately harms collaboration in the project.

## Scope

This code of conduct applies in:

- Issues, pull requests, discussions, and code reviews.
- Project communication channels related to development.

## Enforcement

Maintainers may moderate, edit, or remove content that violates this code of conduct, and may take proportionate action based on the severity of the case.

## Reporting

If you observe inappropriate behavior, report it privately to the repository maintainers, including relevant context and evidence.

---

This document is inspired by open collaboration and mutual respect principles widely used in open source projects.
